# 🚀 Чек-лист оптимизаций и лучших практик .NET (ServiceCRM)

В этом файле зафиксированы все важные архитектурные и производительностные оптимизации, которые мы внедрим и закрепим в проекте.

---

## 1. EF Core Оптимизации (Чтение данных)
- [ ] **`.AsNoTracking()`**: Добавить на ВСЕ `GET` методы в сервисах (`ClientService`, `MasterService`, `ServiceRequestService`), где данные только читаются и не меняются. Экономит до 50% RAM и ускоряет запросы в 1.5–2 раза.
- [ ] **`AsSplitQuery()`**: Применять при множественных `.Include()` (например, заявка + клиент + мастер + платежи), чтобы избежать эффекта декартового произведения (Cartesian Explosion) в SQL.
- [ ] **Пагинация (`.Skip().Take()`)**: Добавить во все списковые методы (`GetClients`, `GetMasters`, `GetServiceRequests`), чтобы не вытягивать из базы миллион записей разом.

---

## 2. База данных (PostgreSQL) & Dapper
- [ ] **Индексы в PostgreSQL (`AppDbContext.OnModelCreating`)**:
  - Индекс на `ServiceRequests.ClientId` и `ServiceRequests.MasterId` (ускоряет JOIN и фильтры в сотни раз).
  - Индекс на `ServiceRequests.Status` и `ServiceRequests.CreatedAt` (ускоряет выборку для Дашборда и Аналитики).
  - Уникальный индекс на `Clients.PhoneNumber` и `Masters.PhoneNumber`.
- [ ] **Dapper для отчетов и Дашборда**:
  - Высокоскоростные агрегатные SQL-запросы (`COUNT`, `SUM`) без накладных расходов EF Core.
- [ ] **Транзакции**:
  - Использовать `IDbContextTransaction` при создании заявки + создании клиента или закрытии заявки + создании платежа.

---

## 3. Кэширование & Сеть (Redis & HTTP)
- [ ] **Redis (`IDistributedCache`)**:
  - Кэш для Дашборда на главной странице (`dashboard_today`) с TTL 30–60 сек.
  - Кэш для месячной аналитики с умной инвалидацией при завершении заявки (`complete`).
- [ ] **CancellationToken**:
  - Пробросить `CancellationToken` во все асинхронные методы сервисов и контроллеров (отмена запроса к базе, если пользователь закрыл вкладку браузера).
- [ ] **Глобальный JSON String Enum Converter**:
  - Конвертация `enum` в читаемые строки (`"New"`, `"Completed"`) в ответах API.

---

## 4. Интеграции & Автоматизация
- [ ] **Webhook «Телегудок»**: Прием звонков и автосоздание заявки.
- [ ] **Telegram Bot (`Telegram.Bot`)**: Уведомление мастера в ЛС + микроопрос при закрытии заказа.
